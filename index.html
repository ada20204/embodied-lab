Nova · Pocket 3 · MuJoCo

从一只机器鸭，
到一台会运镜的机械臂

这里记录一组具身智能实验：读 Microduck 的强化学习训练栈，研究怎么让 Pocket 3 当 AI 的身体，比较机械臂的几条学习路线，最后落到用越疆 Nova 挂 Pocket 3 做影视运动控制。主要产出是一个能在浏览器里直接用的运镜预演台。

打开运镜预演台 → 看开发记录
461° → 42°云台分担后，微俯环绕的手腕总行程

7 项逐帧检查：不可达、干涉、限位、超速、超加速、起停冲击、奇异
3 种Pocket 3 挂法，自动修正会在需要时切换

想法是怎么演进的

  1. 01

    Microduck 与强化学习

    拆解 mjlab + PPO 训练栈、执行器建模和奖励设计。收获：执行器模型决定了大部分 sim2real 差距，奖励要写成硬性规则。笔记 →

  2. 02

    Pocket 3 当 AI 的身体

    结论是不需要 RL，靠程序化动画；找到蓝牙逆向项目和可动 3D 模型，估算视觉闭环 10–30 Hz。笔记 →

  3. 03

    机械臂怎么学技能

    比较 ACT、VLA、π、agentic、RL；梳理越疆 Nova 的 SDK（29999 / 30004 / ServoJ）怎么接进 LeRobot。笔记 →

  4. 04

    转向影视运动控制

    Blender 预演 → 逆解与检查 → ServoJ 执行；数字孪生；Claude 用镜头语法当摄影指导。笔记 →

  5. 05

    运镜预演台 v1 → v4

    从"会撞"到重做碰撞和逆解分支、加动作从容度检查，再到真实尺寸的 Pocket 3、三种挂法和云台分担。笔记 →

  6. 06

    下一步

    计算核心迁到 MuJoCo + mink，做 Blender 插件，真机实测；扩展到双臂和宇树 G1。笔记 →
