# 拍摄 Studio：最佳效果规划

[拍摄 Studio](../studio/) 现在能写镜头脚本、规划 Nova 5 的运动、检查干涉、导出成片。这份规划回答一个问题：**要让预演出来的画面尽量接近“真拿 Nova 5 + Pocket 3 去拍”的成片，还差什么，先做哪个。**

排序原则：先做“画面差距最大、改动最小”的；凡是会让预演和真机素材对不上的效果（比如夸张的虚化）不做，或者按真实参数做。

## 已经有的

- 镜头脚本：节拍、先快后慢、倒放、重复；每个镜头相对主体写，换主体不用改镜头。
- 机械臂：逆解、选分支、限位、速度和加速度换算成“真机放慢倍数”，干涉检测和自动修正。
- 真实外形的 Nova 5、自由视角、全局小窗开关。
- **替换模型**（第一步，已完成）：导入 .glb 当主体，自动摆正（Z 向上、落地、长边沿 x），按实际长度缩放，面数过多自动抽稀，碰撞按包围盒推出的横放胶囊体检查。模型只放内存，脚本里记文件名、指纹和尺寸。
- **高画质导出**（已完成）：1080p / 2K / 4K，2× 超采样抗锯齿，最多 24 次运动模糊采样，可调码率。

## 接下来

### 1. 材质和贴图（对导入模型的观感影响最大）

现在渲染器只读材质的单一基础色，下载来的模型大多靠贴图出涂装、logo 和细节，导进来是一块一块的纯色。

- 读 UV 和基础色贴图（baseColorTexture），这一项就能让大多数模型“认得出来”。
- 再读金属度 / 粗糙度和法线贴图，车漆、碳纤维、轮胎的区别才出得来。
- 着色从现在的经验光照换成简化 PBR（GGX 高光 + 菲涅尔），否则有了贴图也还是塑料感。

代价：渲染器要加纹理通道和新着色器，中等工作量；贴图大的模型（4K 贴图 × 十几张）要在导入时缩到 2K 以内，否则手机会爆内存。

### 2. 灯光：从“跟着镜头转”到“影棚里固定的灯”

现在主光方向跟着机位走，环绕镜头时明暗不变，看不出“绕”的感觉。

- 灯固定在场景里，环绕时高光会在车身上扫过，这一条对质感提升很大。
- 三灯布光写进脚本（主光、辅光、轮廓光的位置、强度、色温），给几个预设：产品暖调、赛车冷调硬光、柔光。
- 环境光用一张简化的影棚环境贴图做反射，车漆和玻璃才有反光。
- 灯也是场景里的物体：画出灯架和柔光箱，参与干涉检测，机械臂扫到灯架会标红（预演台里就有这一项）。

### 3. 阴影和地台

- 现在主体下面是一个圆形的软影子。换成真正的阴影贴图，车轮、尾翼的影子才对得上。
- 网格地面换成无缝影棚地台（地面和背景墙之间是圆弧过渡），可选带一点反射。干净成片里这是“像广告片”还是“像工程软件”的分界线。

### 4. 多物体摆放

- 场景从“一个主体”扩展成“一组物体”：主体（镜头对准它）、道具、灯。
- 在自由视角里点选、贴地拖动、旋转把手、1 cm / 15° 吸附，数字框精确输入。
- 每个物体的碰撞包络可见、可调；导入模型的包络从一根胶囊体细化成 2–4 段，贴合度更好。

### 5. 镜头光学（按 Pocket 3 的真实参数做）

- 景深：Pocket 3 是 1 英寸传感器、f/2.0 定光圈，近距离拍小物体时背景会有一些虚化，但远没有单反那么强。按真实焦距、光圈和对焦距离算，不做夸张的虚化。
- 色彩：导出时可选一个 LUT（比如 D-Log M 转 Rec.709 的观感），让预演和真机素材调色一致。

### 6. 导出

- 运动模糊现在是在 8 位画布上逐次叠加，24 次以上会有轻微色带。改成浮点缓冲累加，采样数就可以放开。
- 逐帧 PNG 序列 / 更高码率，方便进剪辑软件。
- 离线出片工具（`tools/render_reel.py`）跟上网页导出的分辨率和超采样设置。

### 7. 和真机对上

- 每个镜头的关节轨迹已经能导出 CSV；还差一个时间码对照表：真机拍的素材第几秒对应成片第几秒，加速倍数是多少。
- 真机拍完后，把实拍素材和预演成片并排对比，量位置误差。

### 8. 模型存储

现在导入的模型只在内存里，刷新就没了（脚本还在，画同尺寸方块代替）。之后可以：GitHub Pages 版存在浏览器本地（IndexedDB）；Claude 里的 artifact 版存进 artifact 的文件存储。付费模型不适合后一种，因为能打开链接的人都能拿到文件。

## 建议顺序

1. 材质和贴图 + 固定灯光（一起做，单做任何一个效果都打折扣）
2. 阴影和影棚地台
3. 多物体摆放（灯作为物体放进来）
4. 导出的浮点累加和 PNG 序列
5. 镜头光学、真机对照、模型存储
