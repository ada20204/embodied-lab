# 下一步

## 手上的硬件

| 设备 | 用途 |
|---|---|
| 越疆 Nova | 影视运镜臂；之后做 ACT 模仿学习 |
| DJI Osmo Pocket 3 | 末端相机；AI 身体原型 |
| 宇树 G1 | 人形机器人：RL 运动控制、遥操作 + 模仿学习 |

## 近期

1. **真实模型**：拿到 Pocket 3 的 STEP（MakerWorld 可动版），替换近似模型；Nova 换成官方 URDF。
2. **计算核心迁到 MuJoCo + mink**：真实网格碰撞、碰撞避让写成约束、9 轴协同、动力学验证。先拿同一条环绕和网页版结果对比。
3. **实测 Pocket 3 蓝牙控制**：阶跃和正弦指令 + 20 Hz 遥测，测延迟、最大角速度、平滑程度、重复精度。
4. **真机跑通**：低速 ServoJ 执行一条通过检查的镜头，连跑三遍对比画面一致性。

## 中期

- **Blender 插件**：rig、镜头语法面板、编译写关键帧、路径着色、问题帧标记；接数字孪生（关节同步 + 画面叠加）。
- **Agentic 摄影指导**：镜头语法和检查包装成 MCP 工具，Claude 设计分镜、看预演、改参数，执行前由人确认。
- **Nova 上的 ACT**：用 LeRobot 训一个任务，数据集和模型传到 Hugging Face。

## 扩展方向

- **双臂：一只手拍，一只手演**。演员臂转产品、倒液体、撒粉，和运镜精确同步，每一遍都能重复。难点是两臂碰撞、同时抓一个物体时的闭链、两台控制器的时间同步。
- **G1**：用 `unitree_rl_mjlab`（和 Microduck 同一套 mjlab）训运动控制；用 `xr_teleoperate` + `unitree_lerobot` 做双手遥操作和模仿学习；也可以让 G1 当"演员"，或者手持 Pocket 边走边拍。新策略先在仿真里验证，上真机挂保护绳。

## 作为作品集还缺什么

- 学习类方法的成果：ACT 已在越疆双臂上采集训练，并部署到 S100、8550 做过板测（见作品集）；缺的是**当前可复验的真机闭环**和公开可看的视频；
- 真机视频：Nova 挂 Pocket 拍一组镜头，和预演画面并排对比；
- 实测数据：重复精度、蓝牙延迟；
- 能讲清每个设计决策：雅可比与奇异、阻尼最小二乘、逆解分支、PPO、ACT 的动作分块。
